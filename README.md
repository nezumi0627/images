# KCS北九州 奨学生試験 本気対策サイト

KCS北九州情報専門学校の奨学生試験（国語・数学・英語）向けの学習サイトです。

## 機能

- **教科別演習** — 国語28問 / 数学28問 / 英語28問（計84問）
- **4択 + 記述式** — 即時採点と詳細解説
- **60分模擬試験** — 各教科10問ずつ計30問
- **弱点復習** — 間違えた問題を集中復習
- **進捗保存** — localStorageで学習記録を保持

## 使い方

ブラウザで `index.html` を開くだけで利用できます。スマートフォンにも完全対応しています。

## GitHub Pages

`main` ブランチの `index.html` がそのまま公開されます。
